# NAND Gate to 8-Bit Full Adder

A hierarchical **VHDL implementation of an 8-bit Full Adder**, constructed from **NAND gates through 1-bit Full Adder modules**. This project demonstrates hierarchical and structural digital circuit design by connecting multiple 1-bit Full Adders to perform 8-bit binary addition.

## 📌 Project Overview

This project extends the concept of a 1-bit Full Adder to an **8-bit Full Adder**.

The design starts with the basic NAND gate and follows a hierarchical structure:

```text
NAND Gate
    ↓
1-Bit Full Adder
    ↓
8-Bit Full Adder
```

Eight 1-bit Full Adders are connected in sequence so that the carry output from one stage becomes the carry input of the next stage.

This creates an **8-bit ripple-carry Full Adder**.

## 🔗 Design Hierarchy

```text
NAND Gate
    │
    ▼
1-Bit Full Adder
    │
    ├── Full Adder 0
    ├── Full Adder 1
    ├── Full Adder 2
    ├── Full Adder 3
    ├── Full Adder 4
    ├── Full Adder 5
    ├── Full Adder 6
    └── Full Adder 7
             │
             ▼
       8-Bit Full Adder
```

Each 1-bit Full Adder processes one bit position and passes its carry to the next Full Adder.

## 🧩 Components

### 1. NAND Gate

The NAND gate is the fundamental building block.

```text
Y = NOT(A AND B)
```

NAND is a universal logic gate, meaning that digital logic circuits can be constructed using NAND gates alone.

### 2. 1-Bit Full Adder

The 1-bit Full Adder is constructed using NAND gates.

It has:

**Inputs:**

* `A`
* `B`
* `Cin`

**Outputs:**

* `Sum`
* `Cout`

The resulting Full Adder module is then used as a building block for the 8-bit design.

### 3. 8-Bit Full Adder

The 8-bit Full Adder consists of **eight 1-bit Full Adder instances**.

The carry signals are connected sequentially:

```text
Cin
 │
 ▼
FA0 ──C1──► FA1 ──C2──► FA2 ──C3──► FA3
                                      │
                                      ▼
                                   FA4 ──C5──► FA5 ──C6──► FA6 ──C7──► FA7
                                                                          │
                                                                          ▼
                                                                         Cout
```

The eight stages perform addition from the least significant bit (LSB) toward the most significant bit (MSB).

## 🔢 8-Bit Addition

The circuit accepts two 8-bit binary numbers:

```text
A = A7 A6 A5 A4 A3 A2 A1 A0
B = B7 B6 B5 B4 B3 B2 B1 B0
```

along with an initial carry input:

```text
Cin
```

The output is:

```text
Sum  = S7 S6 S5 S4 S3 S2 S1 S0
Cout = Final carry
```

Therefore:

```text
A + B + Cin = Cout + Sum
```

## 🔄 Carry Propagation

The circuit uses a **ripple-carry structure**.

The carry generated by each Full Adder is passed to the next stage:

```text
Cin → FA0 → FA1 → FA2 → FA3 → FA4 → FA5 → FA6 → FA7 → Cout
```

For example:

```text
FA0:
A0 + B0 + Cin → S0 + C1

FA1:
A1 + B1 + C1 → S1 + C2

FA2:
A2 + B2 + C2 → S2 + C3

...

FA7:
A7 + B7 + C7 → S7 + Cout
```

This demonstrates how a larger arithmetic circuit can be constructed by connecting smaller reusable modules.

## 🧪 Simulation & Testing

The project contains VHDL testbenches for verifying the different levels of the design.

Testing includes:

* NAND Gate functionality
* 1-bit Full Adder functionality
* 8-bit Full Adder functionality
* Carry propagation between Full Adder stages
* Different combinations of 8-bit input values
* Final Sum and Carry output verification

The simulation waveforms are analyzed to verify that the circuit produces the expected binary addition results.

## 📊 Example

For example:

```text
A   = 00001111
B   = 00000001
Cin = 0
```

The expected result is:

```text
Sum  = 00010000
Cout = 0
```

Another example:

```text
A   = 11111111
B   = 00000001
Cin = 0
```

The expected result is:

```text
Sum  = 00000000
Cout = 1
```

These examples demonstrate carry propagation through multiple Full Adder stages.
